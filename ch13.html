第 13 章：架构方案演练

章节目标：拿到一条需求，10 分钟内出一页纸架构方案——端云怎么分、成本多少、功耗多少、断网怎么办。这就是架构师每天真正在做的事。

状态：进行中 上午 4h · 3 个任务 下午 4h · 3 个任务 产出目录：ch13-architecture-drill

这一页怎么用（学习流程）

  • 第 1 步 听讲解：读「课堂讲义（板书）」，把端云协同、能力边界、BOM、功耗四块看懂。
  • 第 2 步 填模板：讲义给的「一页纸方案模板」先拿一个场景手填一遍。
  • 第 3 步 交作业：到「练习（交作业）」为三个场景各出一页纸方案。
  • 第 4 步 自测：对着「检验标准」随机抽一个需求，10 分钟内讲出方案。

课堂讲义（板书）

讲解0. 这节课到底学什么

前 12 章是「做出来」；这章是「做决策」。架构师的核心动作就一句话：在成本、功耗、延迟、能力之间做取舍，并说清理由。练法只有一个——拿真实场景反复出方案，直到能条件反射。

讲解1. 板书①：端云协同——什么端侧、什么云端

端侧不是什么都自己干，云端也不是万能。分工原则：高频、低延迟、隐私、离线可用 → 端侧；低频、重算力、要最新知识 → 云端。

端云分工决策表 任务 端侧 云端 ───────────────────────────────────────────── 唤醒词（常驻） ✅ 常驻低功耗 ❌ 语音识别 ASR ✅ 小模型可端侧 ⚠️ 强场景转云 意图识别 ✅ 1.5~3B ❌ 简单多轮对话 ✅ 1.5~3B ❌ 本地知识检索 ✅ RAG ❌ 复杂推理/长文/代码 ❌ 转云 ✅ 大模型 需要最新信息 ❌ → 云 ✅ 隐私敏感数据 ✅ 必须留在端 禁止外发 断网策略：降级到本地 1.5B，只保基础对话 + 本地工具 + RAG。
一句话结论：端云协同的判据是「延迟 / 隐私 / 离线 / 成本」四把尺子——能满足就地端侧，满足不了才上云，且必须设计断网降级路径。

讲解2. 板书②：RK3576 的能力边界（背下来的结论）

架构师要清楚手上的芯片「能吃多大模型」。RK3576 的舒适区很小但很实用。

RK3576 能力边界 舒适区模型规模 ：1.5B ~ 3B int4 / int8 能干的活 ：意图识别、简单多轮对话、RAG 问答、语音唤醒 吃力的活 ：>7B 模型、长上下文(>8K)、复杂数学/代码 真正瓶颈 ：内存带宽 ≈ 35 GB/s（不是 NPU 算力） 实测参考 ：3B int4 ≈ 5~10 tok/s（语音交互够用） 结论：3576 = 中端端侧 AI，定位「意图 + 轻对话」，不是「大模型推理机」。 往上要更强：RK3588（带宽更高）；往下要更省：3576 就够。
一句话结论：RK3576 用 1.5B~3B int4 做意图识别和简单对话是甜点；复杂推理走云端，断网降级到本地 1.5B——这条要能脱口而出。

讲解3. 板书③：BOM 成本拆解

面试官问你「这台设备物料多少钱」，答不出就是没做过产品。BOM 要能拆到主控、内存、存储、传感器、结构。

BOM 拆解模板（示例：本地语音助手） 主控 RK3576 ≈ $12 LPDDR4X 4GB ≈ $6 eMMC 16GB ≈ $3 WiFi/BT 模组 ≈ $3 麦克风阵列(2~4 mic) ≈ $4 扬声器 + Amp ≈ $4 PMIC + 电源 ≈ $2 PCB + 结构 + 组装 ≈ $8 ───────────────────────────── 合计 ≈ $42（留 ~$8 冗余）→ 售价 $49~59 合理 成本敏感点：内存和存储占大头；内存能压到 2~4GB 就别上 8GB。 对照：RK3588 主控更贵（±$10+），BOM 会整体抬高。
一句话结论：BOM 拆解要能报出「主控 / 内存 / 存储 / 外设 / 结构」五块的大致占比，并指出内存与存储是成本杠杆。

讲解4. 板书④：功耗估算与续航

续航不是拍脑袋，是 电池容量 ÷ 平均功耗。平均功耗要从工作剖面推。

功耗估算与续航 待机（仅唤醒词） ≈ 0.3 W 本地 1.5B 语音对话 ≈ 2.5 ~ 3.5 W 峰值（最大推理+喇叭） ≈ 5 W 假设平均 2.5 W，电池 20 Wh（=3.7V × 5400mAh） 续航 = 20 Wh ÷ 2.5 W = 8 h ✅（对齐需求） 要 8h ：电池 ≥ 20 Wh 要 12h：电池 ≥ 30 Wh，或把平均功耗压到 2.0 W 要 4h ：电池 ≥ 10 Wh（可省成本） 常见坑：只按峰值算续航 → 严重高估；要按「带权平均」算。
一句话结论：续航 = 电池容量 ÷ 平均功耗；平均功耗要按工作剖面加权，不能拿峰值或待机糊弄。

讲解5. 板书⑤：一页纸方案模板（本章核心，背下来）

这是本章要你反复练到肌肉记忆的东西。任何端侧 AI 需求，都用这七段回答。

《一页纸架构方案》模板 1. 场景与目标 ：一句话说清「这是什么产品、给谁用」 2. 需求与指标 ：功能清单 + 硬指标（延迟 / 续航 / 成本 / 温度） 3. 端云分工 ：端侧做什么 / 云端做什么 / 断网怎么降级 4. 关键选型 ：SoC / 模型规模 / 量化 / 框架 / 内存预算 5. 成本(BOM) ：主控+内存+存储+外设+结构 ≈ $___ 6. 功耗与续航 ：峰值/平均功耗 → 电池容量 → 续航 7. 风险与取舍 ：最大的 2 个风险 + 应对方案 判据：一页纸、七段齐、每个数字有来源、每个取舍有理由。

拿三个真实场景各走一遍，你会发现「模板不变，数字变」：

场景演练①：本地语音助手 目标：离线可用、隐私、便宜 指标：TTFT<1s, tok/s>8, 续航 8h, BOM $50 端云：端侧全包（唤醒/ASR/意图/对话/RAG），复杂问题转云 选型：RK3576 + 1.5B int4 + RKNN；内存 4GB BOM ：≈ $42 → 售价 $49~59 功耗：平均 2.5W → 20Wh 电池 → 8h 风险：带宽瓶颈 → 靠更狠量化 + 短上下文缓解 场景演练②：车机语音 目标：低延迟、离线安全、车规 指标：TTFT<0.8s, 断网必可用, 宽温 端云：端侧唤醒+意图+短对话；导航/联网内容走云 选型：车规级 SoC 或 RK3576 + 3B int4；内存 8GB BOM ：主控+内存抬高，估算 $___ 功耗：由车电供电，续航不是约束 风险：车规认证 + 热环境 → 降频策略 场景演练③：工业边缘盒子 目标：多路输入、常驻、可靠、可扩展 指标：并发 N 路、7×24 稳定、散热受限 端云：端侧做实时检测/意图；集中管理走云 选型：RK3576 + 1.5B~3B int4；内存 4~8GB BOM ：按路数与接口扩展，估算 $___ 功耗：常驻供电，关注散热与 MTBF 风险：散热→降频；建议无风扇或主动散热
一句话结论：一页纸方案 = 七段模板 × 场景数字；练到「给需求 10 分钟出方案」，你就具备架构师的核心能力。

BOM 与功耗计算器

目标

要掌握

面试话术

可直接背

「拿到一个端侧 AI 需求，我会先做端云分工：高频、低延迟、隐私、要离线可用的放端侧，复杂推理和需要最新知识的放云端，并且一定设计断网降级路径。芯片上，RK3576 我判断它的舒适区是 1.5B~3B int4，做意图识别和简单对话，瓶颈是内存带宽约 35GB/s，复杂推理走云端，断网就降级到本地 1.5B。然后我会算账：BOM 拆到主控、内存、存储、外设、结构，用内存和存储做成本杠杆；功耗按工作剖面算平均，续航等于电池容量除以平均功耗——比如平均 2.5 瓦、20 瓦时电池就是 8 小时。最后落成一页纸，七段：场景、指标、端云分工、关键选型、BOM、功耗续航、风险。比如本地语音助手我会按 $50 BOM、8 小时续航给方案；车机侧重低延迟和车规；工业盒子侧重多路、常驻和散热。每个取舍我都能讲出为什么不选另一个。」

能力标签：架构决策能力——端云分工、芯片选型、成本功耗权衡，一页纸说清（架构师核心能力）。

RK3576 特别提示

  • 定位要说准：3576 是中端端侧 AI，适合「意图 + 轻对话 + RAG」，不要吹它能跑大模型。
  • 瓶颈是带宽不是算力：方案里写优化方向时，优先「降比特 / 减上下文 / 前缀缓存」，而不是「加算力」。
  • 内存是成本杠杆：4GB 够就跑 4GB，别为了跑更大的模型硬上 8GB，BOM 会顶不住。
  • 升级判断：若要跑 >3B 或长上下文，考虑 RK3588（带宽更高）；中端产品 3576 性价比更优。
