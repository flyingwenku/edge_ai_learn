课堂讲义（板书）

讲解0. 这节课到底学什么

前 4 章是通用底座：算内存、选量化、拆框架、跑部署链路。这套东西不管做什么任务都用得上。从本章起进入领域插件——LLM、CV、语音、传感器各有各的输入、网络、指标和量化痛点。但你要记住一句话：领域换的是「最上面一层皮」，底座不动。这一章就给你一把「换皮」的通用工具。

一句话记住：通用能力可迁移，领域差异可枚举。学会这个模板，后面每个领域只是往格子里填内容。

讲解1. 板书①：两层模型——通用底座 + 领域插件

端侧 AI 的知识可以切成两层。下层是跨领域通用的「底座方法」，上层是每个任务领域自己的「插件细节」。搞混两层，就会「LLM 那套调法硬套到检测上」。

两层结构 【上层：领域插件】 每个领域不一样，可枚举 输入模态 / 代表网络 / 预处理 / 评估指标 / 量化敏感点 … 例：LLM 盯「权重离群值」，CV 盯「回归头坐标」 【下层：通用底座】 跨领域通用，可迁移 算内存 → 选方案 → 判瓶颈 → 跑链路 → 验收 例：不管什么模型，先算「多大、占多少带宽」再说别的 关系：底座是方法论，插件是参数表。 换领域 = 换插件的参数，不改底座的方法。

讲解2. 板书②：领域插件模板（7 个维度）

任何一个领域，都可以用下面 7 个维度「解剖」清楚。这 7 格填满，这个领域的端侧落地要点就说全了。

领域插件模板 · 7 维 ① 输入模态 喂进来的是什么？（文本 / 图像 / 音频 / 时序信号） ② 代表网络 这个领域主流用什么结构？（Transformer / CNN / Conformer …） ③ 预处理 从原始信号到网络输入要做什么？（分词 / resize / 分帧 / 滑窗） ④ 端侧框架 跑在什么引擎上？（RKNN rkllm / toolkit2 / CPU …） ⑤ 评估指标 好坏怎么量？（PPL / mAP / WER / F1 …） ⑥ 量化敏感点 哪里最容易掉精度？（离群值 / 回归头 / 特征动态范围 …） ⑦ 端侧成熟度 现在成熟到哪一步？（能否 3B int4 落地 / 是否已量产 …） 用法：拿到一个新领域，先按 7 维填格，缺哪格补哪格。

讲解4. 板书④：换领域只是「换最上面一层皮」

这是本章最重要的一句话。领域再变，底座方法一个字都不改。

通用底座五步（跨领域不变） ① 算内存 模型多大？权重 + KV / 特征占多少？ ② 选方案 fp16 / int8 / int4？哪个框架？ ③ 判瓶颈 算力密集还是带宽密集？ ④ 跑链路 PyTorch → ONNX → RKNN，算子过不过？ ⑤ 验收 PPL / mAP / WER 掉多少？能不能上线？ 换领域时这五步照做，只换「填格子的内容」： LLM 第①步算 KV Cache；CV 第①步算特征图 + 权重； 语音第①步算音频缓存；传感器第①步算滑动窗口缓冲。 方法没变，只是输入不同。
换领域 = 换最上面一层皮 ⟶ 底座五步不变
一句话记住：领域知识学的是「参数表」，底座方法学的是「解题步骤」。参数表会过时，解题步骤可以一直用。

本节要点回顾

技术口径

端侧 AI 的知识分两层：下层是跨领域通用的通用底座（算内存 → 选方案 → 判瓶颈 → 跑链路 → 验收），上层是每个领域自己的领域插件（输入模态、代表网络、预处理、端侧框架、评估指标、量化敏感点、端侧成熟度）。通用能力可迁移，领域差异可枚举。

用 7 维模板把 LLM、CV、语音、传感器四个领域铺成一张对照表，就能横向比出差异：LLM 看 PPL、怕权重·激活离群值；CV 看 mAP / mIoU、怕回归头坐标误差；语音看 WER / 误唤醒率、怕特征动态范围与流式缓存；传感器看准确率 / F1、怕小信号幅度与长尾类别。

结论：换领域只是「换最上面一层皮」——输入定预处理、输出定指标、网络定敏感点，三者都会变；而底座五步（算内存、选方案、判瓶颈、跑链路、验收）和带宽口径不变。所以学新领域，是往 7 维格子里填内容，而不是重学一套方法。

RK3576 特别提示

  • 四个领域在 RK3576 上最终都走 RKNN：LLM 走 rkllm（w4a16），CV / 语音 / 传感器走 toolkit2（int8 为主）。
  • 平台统一带来一个便利：底座五步和带宽口径是通用的——3576 内存 LPDDR5-4800 / 32-bit，理论峰值 ≈19 GB/s；NPU 独占实测 12~16 GB/s；产品场景（多任务抢带宽）7~11 GB/s。
  • 领域差异主要落在预处理与量化敏感点：CV 盯回归头坐标、语音盯特征动态范围、传感器盯小幅长尾信号，LLM 盯权重·激活离群值。
  • 多模态场景（如语音 + LLM）在端侧会同时抢 NPU 与带宽，排期与调度要按「底座第③步：判瓶颈」先算清楚。
